ssm

Connect to EC2 instances, ECS containers, EKS pods and RDS databases through AWS Systems Manager, with no bastion host or open SSH ports.

macOS only · Apple Silicon & Intel GitHub

Run it in Terminal. It asks for your password once, for the AWS installers and the /usr/local/bin/ssm link. Use bash <(curl …) as shown: curl … | bash takes over the terminal's input and the password prompt can't work.

What gets installed

  • Homebrew, if it isn't there already
  • fzf, jq and kubectl from Homebrew
  • AWS CLI v2 and the AWS Session Manager plugin
  • ~/.ssm/ssm.sh, linked as /usr/local/bin/ssm, plus an empty ~/.ssm/config.json

Anything already installed is left as it is, so running the installer again is safe.

Configure

Add an AWS account. This writes ~/.ssm/config.json and your AWS CLI credentials:

ssm config   # → add → account name, AWS profile, region, access keys

Use

ssm ssh        # shell into an EC2 instance or ECS/Fargate container
ssm pod        # shell into an EKS pod
ssm db         # open an RDS tunnel
ssm update     # update to the latest version
ssm version    # print the installed version
ssm uninstall  # remove ssm, and optionally its config and dependencies

Every menu has a flag, e.g. ssm ssh --env staging --app adam. Flags, IAM permissions and required tags are in the README.
